# PHSM

**PHSM: A Post–Hashtag Semantic Matching Framework for Hashtag Recommendation from Multimodal Posts**

Research code and reproducibility materials for the PHSM manuscript.

## Release status

The manuscript-aligned implementation and experiment scripts are being audited before release. This repository is currently **incomplete** and should not yet be used to reproduce the paper's reported results.

The planned release covers the multimodal post encoder, PHSM-T/TP/Full training and evaluation, strict cold-label splitting, leakage-safe prototype construction, independent validation and multi-seed experiments, C4Eval, and the controlled MaCon comparison.

## Data

The underlying Instagram data and image features are not committed here. Availability of dataset identifiers, annotations, and reconstruction instructions is subject to the original data license and privacy constraints.
